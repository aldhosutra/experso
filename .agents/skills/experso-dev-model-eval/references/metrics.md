# Metrics by step

| Step | Sample | Metrics |
|---|---|---|
| extract | One carousel with many slides, two reels | Insights per post; for each idea one candidate split out, grep whether the other kept it; images read |
| group: taxonomy | Full input | Category count and size spread (none far over about 300); does each category have one job? |
| group: assignment | One batch of 150, same taxonomy for both | Primary agreement %, soft agreement (each lists the other's choice in `also`); read the hard disagreements |
| plan | Full input | Steps, frameworks, inputs and quality checks per skill; categories reused across skills; read one skill side by side |
| digest | One category that fits one chunk (80–100 insights) | Verbatim survival of template and example lines (first 6 words of each line found in the digest), items, characters |
| write | One skill with one source category | Frameworks explained concretely, not just named; items linked per step; read the same step side by side |
| merge | One overlapping pair | Disagreements found; both sides' specifics kept; read one step side by side |

## Past results that set the defaults

| Step | Result | Decision |
|---|---|---|
| extract | Sonnet kept every idea, less granular (24 vs 34 insights) | Opus default, Sonnet acceptable |
| taxonomy | Sonnet: 9 categories mixing unrelated jobs; Opus: 18 focused | Opus |
| assignment | 94% agreement, 1 of 150 a real disagreement | Sonnet |
| plan | Sonnet about 30% thinner (12 vs 17 frameworks per skill) | Opus (single call) |
| digest | Templates verbatim: Opus 96%, Sonnet 51%, 70% with small chunks | Opus |
| write | Close once the Opus digest exists | Sonnet |
